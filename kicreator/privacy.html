KICreator 개인정보처리방침

시행일: 2026-11-18

1. 구글 드라이브 이용

KICreator는 사용자가 「드라이브 저장」을 켰을 때에만 구글 로그인을 요청합니다. 요청하는 권한은 drive.file 하나이며, 이 권한으로는 KICreator가 만든 파일만 사용자 본인의 구글 드라이브에 올리고 관리할 수 있습니다. 드라이브의 다른 파일은 읽거나 바꾸지 않습니다.

2. 모으는 정보

KICreator는 사용자의 개인정보·파일·구글 계정 정보를 개발자 서버로 보내거나 모으거나 저장하지 않으며, 제3자와 공유하지 않습니다. 구글 로그인으로 받은 접근 토큰은 사용자의 브라우저 안에서만 쓰이고 짧은 시간 뒤 만료됩니다.

3. 권한 철회

구글 계정 → 보안 → 「타사 앱 및 서비스와의 연결」(myaccount.google.com/connections)에서 KICreator 연결을 언제든 끊을 수 있습니다. 확장 프로그램을 지우면 브라우저에 남은 설정도 함께 지워집니다.

4. Google API 서비스 사용자 데이터 정책

KICreator가 Google API에서 받은 정보의 사용과 전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

Privacy Policy (English summary)

KICreator is a Chrome extension. Only when the user turns on "Save to Drive" does it request Google sign-in with the drive.file scope, which lets it upload and manage only the files it creates in the user's own Google Drive. It does not collect, store, or share any personal data or files with the developer or third parties; access tokens stay in the user's browser. KICreator's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Revoke access at myaccount.google.com/connections. Contact: kupstunion@gmail.com
